# scm-edge

SCM-Edge is a final year project investigating edge-deployable deep learning for induction motor fault diagnosis, combining vibration and electrical signature analysis with a dual-branch 1D CNN, quantized to INT8 and benchmarked on a Raspberry Pi for real-time, on-device inference.

## Datasets

- Mechanical fault dataset: [10.17632/6s3dggj9mw.1](https://doi.org/10.17632/6s3dggj9mw.1)
- Motor current/electrical signature dataset: [10.6084/m9.figshare.27216219](https://doi.org/10.6084/m9.figshare.27216219)
